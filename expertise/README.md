# Expertise

Your 3 texts, 3 institutions and 3 experts. `INDEX.md` is the list; `texts/`, `institutions/` and `experts/` hold one card each; `sources/` holds the raw material behind them.

**To add one:** `/gather <name>`. Claude makes the card, the sources folder and the INDEX row, and marks what it could verify.

**By hand:** copy `<type>/_template.md` to `<type>/<slug>.md`, add a row to `INDEX.md`, and make `sources/<slug>/` with a `_source.md` listing what is in it and where it came from.

# Sources

Raw material for `/consult`: one folder per source, named with a short slug (`peter-zumthor`, `atmospheres-zumthor-2006`).

Good material: transcripts of talks and interviews, lecture notes, your own reading notes with page numbers, short quotes, articles you are allowed to keep, PDFs from JSTOR for your own study.

Each folder has a `_source.md` saying what is in it and where each file came from. `/gather` sets this up.

Do not put full copyrighted books here. Notes and short quotes are fine.

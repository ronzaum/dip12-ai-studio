AI sessions: setup guide

AI makes options cheap. Taste decides which one is right. You will deploy multiple agents, give them context, and build the repositories and AI environments they run in. You will build cool things, test ten versions in the time one used to take, and learn to tell which is the good one.

Toolkit

Claude. An autonomous coding agent on your laptop: it reads your files, writes and runs code, and ships working tools, decks and models. Codex is a great optional extra.

Git + GitHub. Version control for design: every iteration is a commit you can branch, diff and roll back, synced to the cloud so nothing lives on one laptop.

Familiar. A local screen-to-text memory: everything you work on becomes searchable context your agent can read. On‑device only, passwords redacted.

Set up · all three required
01

Claude

  1. Go to claude.ai and sign up for the Pro plan (about £18 a month).
  2. Download the desktop app from claude.ai/download. Install it and sign in.
  3. Open the Code tab at the top of the app. That is Claude Code.
02

Git + GitHub

  1. Sign up for a free account at github.com.
  2. Install Git. Mac: open Terminal, type git --version, press Enter, click Install when asked. Windows: download from git-scm.com and install with the default options.
03

Familiar

  1. Download from looksfamiliar.org. Drag it into Applications and open it.
  2. When asked, allow Screen Recording (System Settings → Privacy & Security → Screen Recording → Familiar on). Reopen Familiar if it asks.
  3. Leave it running. It lives in the menu bar.
Have ready
  • Your files reachable from your laptop. If they live in Dropbox, Google Drive, OneDrive or iCloud, have that app installed and signed in.
  • Your logins for Claude, GitHub and your storage, at hand. Do not share them with anyone.

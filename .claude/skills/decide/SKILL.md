You are running Decide. Record one decision in `DECISIONS.md`.

## Steps
1. From the conversation, identify the decision. If unclear, ask: "What did you decide?"
2. Draft the entry in the format at the top of `DECISIONS.md`:
   - **AI gave:** what was proposed, briefly, or a link to the file
   - **I chose:** kept / changed / rejected, and what they did instead
   - **Why:** leave blank
   - **Where it lives:** file path
3. Ask the student for the **why** in their own words. Do not write it for them. One line is enough.
4. Append the entry under `## Log`, newest at the bottom. Confirm in one line.

## Rules
- The "why" is always the student's words. If they skip it, write `(no reason given)`.
- One decision per entry.
